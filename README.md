# CBOR入門
 
技術同人誌「CBOR入門」のサンプルコードリポジトリです。
 
## 本書について
 
本書は、データエンコーディングフォーマットの1つである **CBOR（Concise Binary Object Representation）** を解説した技術同人誌です。
CBORはバイナリ形式・スキーマレスなエンコーディングフォーマットで、パスキー（CTAP2）やモバイル証明書（ISO 18013-5）などで採用されています。
 
## 対象読者
- CBORをより体系的に理解したい方
- JSONやバイナリ形式のエンコーディングフォーマットに触れたことがある方
 
JSONの基本的な知識があれば、スムーズに読み進められます。
 
## 本書の構成
- **1章** データエンコーディングの概要と歴史、CBORの活用事例
- **2章** CBORの基本的なエンコーディング、CDDL、COSE
- **3章** MessagePack・Protocol Buffers・ASN.1との比較
